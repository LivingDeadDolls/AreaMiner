AreaMiner — Fabric MOD

1つのjarでクライアントとサーバーの両方に対応します。
・クライアントに入れると、設定画面と専用キーが使えます。シングルプレイでも範囲破壊が動きます。
・Fabricサーバーのmodsに入れると、Paperプラグインと同じ範囲破壊をFabricサーバーで使えます。
・Paperサーバーへ接続した場合は設定クライアントとして動き、範囲破壊はプラグインが行います。

導入
modsフォルダーへ次の2ファイルを入れてください。
・AreaMiner-fabric の jar
・Fabric API（https://modrinth.com/mod/fabric-api）
対応するMinecraft・Fabric Loader・Fabric APIのバージョンは、各リリースに記載しています。
Fabric APIは古い版と同時に2つ入れず置き換えてください。
クライアント: ゲームディレクトリ/mods
Fabricサーバー: サーバーフォルダー/mods（同じjarです）
このMODをPaperサーバーのpluginsへ入れないでください。Paperには AreaMiner-paper の jar を使います。

言語
設定画面・キー設定・チャットのメッセージは、ゲームの言語設定に従います（日本語・英語。その他の言語は英語）。

シングルプレイ・Fabricサーバーでの動作
範囲破壊・鉱脈・ハイライト・ドロップ移動・耐久倍率・コマンド /areaminer はPaper版と同じです（docs/paper.txt）。
MODのないプレイヤー（バニラクライアントなど）もFabricサーバーに参加でき、
コマンドとスニーク＋オフハンド交換で使えます。範囲ハイライトも本人だけに表示されます。
Paper版との違い:
・権限: Paper版と同じ areaminer.use（既定で全員）と areaminer.admin（既定でOP＝権限レベル2以上）。
  LuckPermsなど fabric-permissions-api に対応した権限MODで変更できます（このAPIはMODに同梱）。
  シングルプレイでは「チートの許可」がONのときに reload を使えます。
・保護: 追加ブロックごとにFabricのブロック破壊イベントを通します。
  このイベントで破壊を止める保護MODでは保護領域が守られます。WorldGuardはFabricにはありません。
  バニラのスポーン保護範囲内の追加ブロックは掘りません。
・設定ファイル: config/areaminer/config.json（ブロックIDは minecraft:stone の形式）
  鉱脈の設定（vein-mining・vein-max-blocks・ores）もPaper版と同じです。
  個人設定: config/areaminer/players.json（UUIDごと）
  シングルプレイでは全ワールド共通です。
・設定再読込は /areaminer reload。

設定画面
Minecraftの「設定」の上段（視野・オンライン設定の行）にツルハシのアイコンボタンを追加します。
Mod Menuを入れている場合は、MOD一覧のAreaMinerの設定ボタンからも開けます。
独立した専用画面で設定できます。
一般: ハイライト、ドロップ位置、耐久値。修飾キー・切り替えキー・設定画面キーはキー設定画面を開きます。
範囲: 平面・立体・階段・整地の行ごとに X・Y・Z（ボタンにマウスを乗せると意味を表示）。
  平面 X=幅 Y=高さ ／ 立体 X=幅 Y=高さ Z=奥行き（各1～10、1×1は不可）
  階段 X=幅（1～10） Y=高さ（2～10） Z=段数（1～10）
  整地 X=幅 Z=奥行き Y=高さ（足元から上。各1～10、1×1×1は不可）
ツール: ツルハシ、シャベル、斧、クワ、ハサミ、素手、その他を個別にON/OFF。
「その他」には剣など、上記以外のアイテムを含みます。
「全ツール」はツルハシ・シャベル・斧・クワ・ハサミをまとめて切り替えます（素手・その他は個別に）。
ツールをOFFにすると、そのツールでは範囲破壊せず通常の1ブロック採掘になります。
すべてOFFなら範囲破壊・範囲ハイライトは作動しません。
画面で編集したら「保存・適用」。戻るだけなら未適用の編集を取り消します。
範囲を変更しても範囲破壊モードは切り替わりません。
対応サーバー（Paperプラグイン・Fabric MOD・シングルプレイ）へ接続すると個人設定を取得します。
未接続でも設定を保存でき、次の対応サーバー接続時に反映します。
AreaMinerのないサーバーでは、接続から約5秒たっても応答がないとチャットで一度だけ知らせ、MODの切り替えキーをオフにします（押すとホットバーの上に「このサーバーでは AreaMiner を使えません」と表示し、キー本来の操作はそのまま行います）。
サーバーのAreaMinerとバージョンが合わないときもチャットで知らせます。その場合はサーバー側のスニーク＋オフハンド交換か /areaminer で切り替えられます。
使用権限がない場合や設定保存に失敗した場合は画面にエラーを表示します。

専用キー
Minecraftの「設定」→「操作設定」→「キー設定」にAreaMinerの項目を追加します。
・範囲破壊モードを切り替える: 初期はF
・切り替えの修飾キー: 初期は左Shift
・AreaMiner設定を開く: 初期は未割り当て
キー本体は自由に変更でき、マウスボタンも使用できます。
修飾キーを押しながら切り替えキーを押すと切り替わります。初期設定はShift＋Fです。
Shift・Ctrl・Altは左右どちらでも反応します。修飾キーの割り当てを外すと、切り替えキーだけで切り替わります。
スニークやオフハンド交換の割り当てには追従しません。
例: 切り替えキーをR、修飾キーを割り当てなし → Rだけで範囲破壊モード切り替え。
例: 切り替えキーをマウスの追加ボタン、修飾キーを左Ctrl → Ctrl＋そのボタンで切り替え。
設定画面を開く専用キーには修飾は不要です。
対応サーバー接続中、指定した操作は通常のオフハンド交換や他の同じキー操作より優先します。
MODが接続したプレイヤーは、サーバー側のスニーク＋オフハンド交換での切り替えを無効にします。
MODなしのプレイヤーは、スニーク＋オフハンド交換で切り替えます。
キー設定画面ではFやShiftの重複表示が出ますが、そのままで問題ありません（スニークやオフハンド交換も通常どおり動きます）。

モード
OFF → 平面 → 立体 → 階段 → 整地 → OFF の5状態だけを切り替えます。
範囲はキーでは変えません。範囲はコマンドでも設定できます。
ログイン時はOFF。保存・適用で実行中の範囲破壊を止め、次の採掘から反映します。

保存先
クライアント: ゲームディレクトリ/config/areaminer-client.json（設定値・未反映フラグ）
専用キー（修飾キーを含む）: Minecraft通常のoptions.txt
Paperサーバー: plugins/AreaMiner/players.yml（UUIDごとの個人設定）
Fabricサーバー・シングルプレイ: config/areaminer/players.json
MODで変えた設定もコマンドで変えた設定も、サーバー側に保存されます。
サーバー権限・保護判定・対象素材はサーバー側で管理します。
Java版専用です。統合版にはFabric MODを導入できません。

ビルド
Java 25 で ./gradlew build（Windows は gradlew.bat build）を実行します。
