AreaMiner — Paperプラグイン

導入先
Paperサーバーの plugins フォルダーへ AreaMiner-paper の jar を入れてください。
サーバーの次回起動で反映。稼働中の /reload は使用しないでください。

言語
チャットのメッセージは、各プレイヤーのゲームの言語設定に従います（日本語・英語。その他の言語は英語）。

キー操作
スニーク＋オフハンド交換（標準Shift＋F）で次の5状態だけを切り替えます。
OFF → 平面 → 立体 → 階段 → 整地 → OFF
範囲はキー操作では変わりません。通知は本人だけに表示。
Minecraftのキー設定で「スニーク」「オフハンドとアイテムを交換」を変更すると追従します。
AreaMiner独立の専用キー項目はありません。Fだけなら通常のオフハンド交換です。
モードはログイン時にOFF。範囲・ハイライト（色も）・ドロップ位置・耐久・対応ツールは個人ごとに保存します。

モード指定
/areaminer             次のモード
/areaminer next        次のモード
/areaminer off         OFF
/areaminer plane       平面（「平面」でも可）
/areaminer cube        立体（「立体」でも可）
/areaminer stairs      階段（「階段」でも可）
/areaminer flatten     整地（「整地」でも可）
/areaminer status      現在のモードと個人設定
/areaminer help        ヘルプ

範囲指定（範囲を変えて、そのモードに切り替えます）
/areaminer plane 3            平面を3×3に
/areaminer plane 3 5          平面を幅3×高さ5に
/areaminer cube 3             立体を3×3×3に
/areaminer cube 3 3 10        立体を幅3×高さ3×奥行き10に
/areaminer stairs 2 3 4       階段を幅2・高さ3・4段に
/areaminer flatten 5          整地を5×5・高さ5に
/areaminer flatten 7 5 10     整地を幅7×奥行き5・高さ10に
平面・立体の各辺は1～10（1×1だけは不可）。初期値は平面3×3、立体3×3×3。
幅は左右、高さは壁なら上下・床や天井なら前後（向いている方角基準）、奥行きは掘る面の奥。
階段は幅1～10・高さ2～10・段数1～10（最大1000ブロック）。初期値は幅2・高さ3・4段。
整地は幅・奥行き・高さの各1～10（1×1×1は不可、最大1000ブロック）。初期値は5×5・高さ5。
平面・立体・階段・整地の範囲はそれぞれ別に保存され、キーで切り替えても保持されます。
Tab補完で指定できる値を表示します。

個人設定（MOD不要のゲーム内コマンド）
/areaminer highlight on      ハイライトON（初期値）
/areaminer highlight off     ハイライトOFF
/areaminer color red         ハイライトの色（初期値 aqua）。aqua・white・red・orange・yellow・lime・blue・purple・pink
/areaminer color #FF8800     ハイライトの色を #RRGGBB で指定
/areaminer color gaming      ゲーミング（虹色が範囲を流れるように光る。rainbow でも可）
/areaminer color gaming 4    ゲーミングの速さ（1～8。1周は「10－速さ」秒で、1で9秒、初期値2で8秒、8で2秒）
                             9～12 は設定ファイルを書き換えたときだけ使える（動作保証なし。下の「ゲーミングの速さ」）
                             範囲が大きいときは通信量を抑えるため、色の変わり方を段階的にし、さらに大きく速いときは更新の間隔を広げます
                             （1人あたり色の更新は毎秒2000回まで、約20KB/秒。立体3×3×3程度ならなめらかなまま）
/areaminer drops feet        アイテムを本人の足元に移動（初期値）
/areaminer drops block       通常の破壊位置にドロップ
                             サーバー設定の drops が player 以外のときは変更できません（下記）
/areaminer durability normal 耐久消費は通常どおり（初期値、1でも可）
/areaminer durability half   耐久消費を半分にする（0.5でも可）
/areaminer durability none   耐久を消費しない（0でも可）
対応ツールは初期状態でツルハシ・シャベル・斧・クワ・ハサミ（素手とその他のアイテムでは範囲破壊しません）。FabricクライアントMODの専用画面で種類を選択できます。
MOD接続時はスニーク＋オフハンド交換での切り替えを無効にし、MODの独立した専用キーを使います。
MODの画面では範囲・ハイライト・ハイライトの色・ドロップ位置・耐久も設定でき、同じ個人設定に保存します。
/areaminer tools all（ツルハシ・シャベル・斧・クワ・ハサミを有効に）または tools 数値でも指定可能。ビット値はツルハシ1・シャベル2・斧4・クワ8・ハサミ16・素手32・その他64の合計（0～127）。
設定はplugins/AreaMiner/players.ymlにUUIDごとに保存します。
変更時は進行中の範囲破壊を停止し、次の採掘から新設定を使います。

破壊範囲
最初に手動で壊したブロックを基点にします。
平面は壊した面に沿った長方形。地面は水平、壁は垂直。
立体は基点から面の奥へ奥行き分掘り、プレイヤー側へは広げません。
壁では、高さ方向はプレイヤーの足元の高さから上へ高さ分。
ただし基点がこの範囲から外れる場合は、基点が入るように範囲を上下にずらします
（高い所を掘ると上へ、足元より低い所を掘るとその高さから）。
壁の横方向と、地面・天井の前後左右は基点が中心です。
偶数の辺は中心が決まらないため正方向へ1多く広がります（2幅は正方向へ1、10幅は負方向へ4・正方向へ5ブロック）。
対象の石・土が混在していても掘り、間の対象外素材の奥も範囲内なら処理します。
階段の横方向は視線に近い東西南北。幅は進行方向の右へ広がります。
最初に壊すブロックを1段目の通路の下端にしてください。
上を向くと1ブロック進むごとに1段上り、水平・下向きなら1段下ります。
通路の床の下は範囲外。階段ブロックを設置する機能ではありません。
整地は足元の高さを床にして、そこから上を高さ分、平らに削ります。
足元より低い所を壊したときは、壊したブロックの高さを床にします。
横方向は基点が中心で、幅は左右・奥行きは前後（向いている方角基準）。偶数の辺は平面と同じく正方向へ1多く広がります。
範囲内は空気をはさんでも続けて掘ります（張り出しや洞窟の天井も高さ内なら消えます）。床より下の埋め立てはしません。
砂や砂利が残らないよう、上の段から順に掘ります。

鉱脈
モードON中（平面・立体・階段・整地のどれでも）に鉱石を掘ると、範囲の代わりにつながっている同じ鉱石をすべて掘ります。
面だけでなく辺・角で斜めに接している鉱石もつながりとして扱います（周囲26方向）。
石の鉱石と深層岩の鉱石は、同じ種類なら同じ鉱脈です（例: 鉄鉱石と深層岩の鉄鉱石）。種類の違う鉱石は別です。
1回の上限は vein-max-blocks（初期値64、最初の鉱石を含む）個で、最初に掘った鉱石から各方向16ブロック以内。
その鉱石をドロップさせられるツール（例: 鉄鉱石なら石以上のツルハシ）のときだけ鉱脈で掘ります。それ以外は通常の1個の採掘です。
対象は ores の一覧（初期値はバニラの全鉱石と古代の残骸）。vein-mining: false で無効になり、鉱石は通常の採掘に戻ります。
耐久消費・ドロップ移動・保護判定・ハイライトは範囲破壊と同じです。

ドロップ・ツール・耐久
AreaMinerがONで対象素材を掘った場合、最初のブロックと追加ブロックのアイテムを対象にします。
既存のドロップを次tickに本人の足元へ移動し、追加アイテムは生成しません。
イベント取消や他プラグインが削除したドロップは移動しません。
自動インベントリ収納ではありません。経験値の発生位置は通常どおりです。
OFF時や対象外素材は通常のドロップ・通常の耐久です。
各ブロックをPaperのPlayer.breakBlockで処理し、適正ツール・シルクタッチ・幸運・経験値は通常に従います。
不適正ツール（例: 石をシャベルで）でも範囲処理しますが、通常ドロップのない組み合わせではアイテムなし。素手は tools で有効にした場合のみ範囲処理します。
耐久の個人設定はAreaMinerの対象採掘にだけ適用。通常採掘・戦闘等には適用しません。
耐久力エンチャントで軽減された消費に倍率を掛けます。
半分の端数はログイン中に累積し、1になった時点で消費します。
耐久消費設定を変える、MODの画面で保存する、または再ログインすると端数はリセットします。
ツールが壊れた／持ち替えたら処理を停止。クリエイティブは通常どおりドロップ・耐久消費なし。

範囲ハイライト
モードONかつ個人設定ONで、視線先から掘る候補を本人だけに発光キューブで表示します（色は個人設定、初期値は水色）。
ブロック内に少し小さいキューブを重ね、壁越しの範囲確認に利用します。
5tick（通常約0.25秒）ごとに更新。最大1000個の表示エンティティを使用。
サバイバル4.5・クリエイティブ5ブロック以内の視線先が対象。
OFF、対象から視線を外す、ログアウト、プラグイン停止で表示を解除します。
対象素材・読込済みチャンク・ワールド境界を反映します。
保護領域の許可・残り耐久は事前判定せず、実際の採掘時に判定します。

ゲーミングの速さ（9～12、動作保証なし）
画面とコマンドで選べるのは1～8（1周9～2秒）です。それより速くしたいときは設定ファイルを書き換えます。9で1秒、10～12で0.5・0.3・0.25秒。動作は保証しません。
・Fabric クライアント MOD: ゲームを閉じて config/areaminer-client.json の "gamingSpeed" を書き換える。次にサーバーにつないだときに送られます。
・サーバー側: サーバーを止めて plugins/AreaMiner/players.yml（Fabric は config/areaminer/players.json）のそのプレイヤーの gaming-speed を書き換える。

サーバー設定・権限
plugins/AreaMiner/config.yml
materials: 石・土・砂・砂利など47種。鉱石は ores（鉱脈）で扱う。木材・チェスト・岩盤は初期状態では対象外。
require-sneaking: true（falseならオフハンド交換だけで切り替え）
show-join-help: true（参加時に「AreaMiner: [範囲破壊] OFF」、日本語以外の言語では「AreaMiner: OFF」を表示。falseで非表示）
preview-enabled: true（falseなら全員の表示を無効化。個人設定ONでも表示しません）
blocks-per-player-per-tick: 64 / blocks-total-per-tick: 256
vein-mining: true（falseなら鉱脈破壊を無効にし、鉱石は通常の採掘）
vein-max-blocks: 64（1回の鉱脈破壊の上限。最初の鉱石を含む。1～1000）
drops: player（範囲破壊・鉱脈のドロップ位置。player=各プレイヤーが選ぶ／feet=全員足元／block=全員破壊位置。
  player 以外では /areaminer drops とMODの画面のドロップのボタンで変更できなくなり、個人の設定は保持したまま上書きします）
ores: 鉱脈として掘る鉱石。バニラの全鉱石（深層岩版・ネザー金鉱石・ネザー石英鉱石を含む）と古代の残骸。
/areaminer reload は設定再読込。OPまたはareaminer.admin権限が必要。
areaminer.use は既定で全員。areaminer.admin は既定でOP。

保護と停止
最初の破壊がキャンセルされた場合は範囲破壊しません。
追加ブロックごとにBlockBreakEventを発生させ、WorldGuard等の保護判定を通します。
バニラのスポーン保護範囲内の追加ブロックは掘りません（OPは除く）。
未読込チャンク・ワールド境界外は追加採掘しません。
モード・個人設定変更、ログアウト、ワールド移動、持ち替え、基点から32ブロック超の移動で停止。
追加採掘から連鎖的に範囲を拡大しません。

ソースとビルド
Java 25 で ./gradlew build（Windows は gradlew.bat build）を実行します。
